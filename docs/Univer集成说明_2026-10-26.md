# Univer 与 LabMate 教师模板设计器的组合接入

日期：2026-10-26。此实现保留原编辑器，增加可切换的增强画布；没有复制 Univer 仓库或用其工作簿取代后端模板模型。

## 已接入范围

- 固定版本 1.2.0，通过包管理器引入 Apache-2.0 开源插件：core、design、docs、docs-ui、engine-render、sheets、sheets-ui、ui。Docs 相关插件是表格文字渲染的依赖，并非新增一套实验报告编辑器。
- `SpreadsheetTableEditor.vue` 继续持有模板、选区、物理量绑定、工具栏、批量设置及撤销/重做。每张表仍由原有 `TemplateTable` 表示。
- `UniverTableCanvas.vue` 在点击“增强表格”后才加载，提供画布、鼠标选择和 Univer 的键盘选区命令。卸载时释放实例、订阅、定时器和 DOM 监听。
- 双击标题/说明或按 F2/Enter，弹出 LabMate 原有的 `PhysicsNotationInput`。编辑确认、保存和切回原表格均进入同一份草稿及历史。
- 表格文字粘贴接受 Excel 的制表符分列、换行分行，以及带引号的多行内容。支持粘贴面板和增强画布的纯文本粘贴。
- 保留原有 Word/Excel 后端导入、发布校验与不可变模板版本。没有新增或变更后端数据模型及 API。

## 数据与操作边界

`TemplateTable → univerAdapter.ts → Univer 画布 → 受控编辑事件 → 原 TemplateTable → 原保存/校验/发布 API`

画布是投影，LabMate 草稿是唯一持久化来源。稳定的字段 key、符号、单位、类型、共享属性和计算依赖均保留在原模型中；不能从工作簿显示文字推断字段绑定。

- 标题和说明始终以字符串单元格投影，`=SUM(...)` 等文本不生成公式。未注册公式引擎、公式插件、Pro 转换、网络协同或 AI 插件。
- 对整个粘贴区域先校验，再一次性写入。任一目标为绑定输入格、合并区域内部、未知单元格或越界时整批拒绝，不静默扩表或截断。
- 输入格不能直接编辑或被普通粘贴覆盖。教师可以继续通过原有“用途/测量项”设置明确改变绑定。
- 行列数量、合并/拆分、宽度和顶部冻结仍由原工具栏处理，再投影回增强画布。尚未开放 Univer 原生结构拖拽、任意格式或多表标签，避免产生当前 schema 无法保存的状态。
- Ctrl/Cmd + Z、重做和工具栏操作使用 LabMate 的同一份表格历史；不依赖另一套隐藏工作簿历史。
- 保存前逐个确认表格的未完成文字编辑；切换新模板时重新创建表格组件，防止旧模板撤销历史串入新模板。

## 样式、性能与兼容性

原有板块配色和按钮悬停样式保留。全局表单规则排除增强画布子树，避免影响第三方控件尺寸；画布外的物理量面板仍使用 LabMate 样式。Univer 与 Vue 实例不进入深层响应式代理。

复杂数学符号的完整预览继续由原物理符号输入器和原表格提供；增强画布按文字显示相同源码，不会把它解释为工作簿公式。卸载前同步处理 React 待执行刷新，避免 Vue 快速切换界面时仍有刷新引用已释放的工作簿。

增强组件采用动态导入，登录、学生录入和未启用增强画布的教师页面不加载它。构建仍会提示增强组件超过 500 kB；依赖包含 React 和文字渲染，后续可继续测量和优化。原表格作为低性能设备与手机的可用入口保留；手机真实触控和输入法仍需设备验收。

## 验证与维护

- `tests/univer-adapter.spec.ts`：字段元数据保留、合并/冻结/列宽投影、文本与公式边界、Excel 多行粘贴、错误区域原子拒绝。
- `e2e/univer-template.spec.ts`：真实浏览器加载画布、编辑未确认文字时保存、新旧编辑器往返、选区与合并、撤销、粘贴保护、原发布 API，以及窄屏布局。API 使用合成数据模拟，不能替代后端鉴权与 PostgreSQL 验收。
- `pnpm test` 运行单元与组件测试；`pnpm build` 检查 TypeScript 和生产构建；`pnpm e2e:univer` 启动静态预览运行上述独立浏览器验收。
- `public/licenses/Univer-Apache-2.0.txt` 保存依赖分发的完整许可证，构建后随静态资源发布。上游版权归 DreamNum Co., Ltd.，本项目的适配器和组合界面独立维护。

本次验证：前端 25 项单元/组件测试通过；TypeScript 与生产构建通过；3 条浏览器流程重复两轮，共 6 次通过；离线冻结锁文件安装通过。浏览器流程覆盖真实画布与剪贴板，但后端接口使用模拟数据。

采用官方公开的插件、Facade、事件和命令接口，依赖锁定同一版本。升级时先运行适配测试和浏览器流程，尤其检查字段绑定、复制粘贴、选区同步及卸载释放。

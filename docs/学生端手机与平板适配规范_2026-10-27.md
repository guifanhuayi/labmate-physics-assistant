# 学生端手机与平板适配规范

更新日期：2026-10-27。用户确认：学生主要通过手机和平板填写实验，学生端以触控移动设备为设计和验收基准；电脑只作兼容。此要求已同步到产品与技术开发规格第 2.3 节、README 和项目交接。原规格中的“手机和电脑录入”已修订，教师/管理员桌面工作台不受此设备定位调整影响。

## 布局约束

- 覆盖共同登录/学生首次设置、学生任务列表、动态数据录入、实验说明、自动保存状态、冲突处理；后续附件、正式提交、历史记录与教师反馈必须遵守同一约束。
- 使用真实设备视口宽度和流式排版，支持浏览器缩放，禁止写死桌面画布后缩小整页。以 320 CSS px 为最窄支持视口，不按物理屏幕像素或设备型号写固定布局。
- 手机采用单栏，页边距 12 px；平板使用较宽留白和合理内容上限。标题、账号、日期、错误提示和操作区可换行，页面整体不应横向溢出。
- 复杂表格保留模板行列、合并结构、字段 ID/绑定、符号、单位、必填与共享属性。只允许表格容器横向滚动，并给出可见提示及可聚焦的滚动区域；不能裁剪字段、隐藏操作或缩小字体来消除溢出。
- 输入字体至少 16 CSS px，触控按钮至少 44 CSS px 高；继续保留颜色区分、边框、键盘焦点。鼠标悬停反馈不作为手机操作的必要条件。

## 数字键盘与旋转

- 手机/平板使用独立的屏幕底部数字键盘，显示当前测量项、符号、单位及当前值，保留数字、小数点、负号、删除、清空、完成能力。
- 不将数字键盘塞进数据表单元格，防止列宽和表格高度随聚焦发生大幅变化。为键盘和设备底部安全区留出滚动空间，聚焦数值格后将其移到键盘上方。
- 使用实时媒体查询：窄屏（不超过 1024 CSS px）或粗指针触屏启用触控键盘；超过 1024 px 的触屏平板横屏仍启用。宽屏精细指针可继续使用实体键盘。
- 屏幕高度不超过 520 px 时使用较紧凑的五列键盘并取消学生页头吸顶，减少横屏遮挡。键盘限制最大高度并可滚动。
- 旋转、分屏、窗口缩放应立即重排，不能重新请求初始化、重置表单、清空未同步记录或更换草稿键。

## 不得改变的功能

布局适配不得修改 API、模板版本、字段键、服务端授权、正式提交规则、格式校验或数据模型；不得更改 IndexedDB 缓存命名、个人/共享数据归属、自动同步、防静默覆盖、离线恢复、冲突选择及只读禁用条件。原有教师模板编辑器及 Univer 切换继续保留。

当前仍不包含阶段 5 正式提交、附件冻结、水印与导出；不要把适配完成写成这些功能已完成。

## 验收矩阵

以下均为 CSS 视口，表格的局部横向滚动是允许行为，整页横向溢出不是。

| 设备场景 | 视口 |
| --- | --- |
| 小屏手机 | 320 × 568 |
| 手机竖屏 / 横屏 | 390 × 844 / 844 × 390 |
| 平板竖屏 / 横屏 | 768 × 1024 / 1024 × 768 |
| 较大平板竖屏 / 横屏 | 820 × 1180 / 1180 × 820 |
| 电脑兼容 | 1440 × 900 |

自动回归入口：

```powershell
cd frontend
pnpm build
pnpm test
pnpm e2e:student
```

`playwright.student.config.ts` 启动独立 Vite preview，使用模拟 API，不改动本地演示账号或真实实验数据。每个设备场景检查任务列表/录入页面无整页溢出、合并表头、数值/文本/选项录入、个人/共享保存、断网刷新恢复、冲突解决、旋转保持数据与只读限制；另检查登录/首次设置页面及桌面与窄屏切换。截图输出到 `frontend/test-results/`。

必须补充真实手机/平板人工验收：iOS Safari、Android Chrome、平板横竖屏/分屏、刘海和底部安全区、系统文本键盘弹出/收起、200% 字号/缩放、长列表滚动与表格横滑、弱网重连。自动化模拟无法证明这些真实设备体验已通过。

2026-10-27 本次验证结果：前端生产构建通过；Vitest 25 项通过；Playwright 最终 18 项通过（7 项为仅适用于桌面断点切换的用例在移动项目中按设计跳过）。7 种手机/平板视口和桌面兼容均覆盖，包含数字键盘打开时旋转屏幕、当前输入保持可见和数据保留。截图使用模拟学生与模拟 API：[手机预览](student-phone-preview-2026-10-27.png)、[平板预览](student-tablet-preview-2026-10-27.png)。真实设备人工验收尚未执行。

## 代码落点

- `frontend/src/styles/base.css`：学生页专用布局和共同登录移动样式，不改变教师页布局。
- `frontend/src/pages/StudentWorkspacePage.vue`：任务卡片的手机/平板排列。
- `frontend/src/pages/StudentAssignmentPage.vue`：局部表格滚动、屏幕底部数字键盘及实时尺寸响应；保留原数据持久化和共享/冲突逻辑。
- `frontend/index.html`：视口及安全区声明，保留浏览器缩放能力。
- `frontend/e2e/student-responsive.spec.ts`、`playwright.student.config.ts`：设备矩阵及行为回归。

后续学生端改动应先对照此清单，再同时检查手机、平板横竖屏；不能仅以桌面浏览器宽窗口截图作为交付依据。

# 手机、平板填写实验表格：GitHub 项目与模块调研

核查日期：2026-10-26（北京时间）。面向 LabMate 的学生现场数据录入，重点核查触屏、数字输入、重复测量、表格/卡片布局、离线保存和 Vue 3 接入。

本次核查 README、实际源码、官方文档、许可证及仓库元数据；没有安装这些候选，也没有做 iPhone/iPad/Android 真机测试。下文区分已看到的实现、作者文档声明与适配建议，不能将“响应式布局”直接当作触屏输入验收。

## 结论

建议保留 LabMate 的后端、稳定字段 ID、模板版本和草稿同步，按需要吸收移动端录入组件。

- **直接改善现有 Vue 手机录入：Vant。** 有真实数字键盘和触屏处理，不是整套实验系统。
- **模板驱动的手机重复测量：FormCreate Vant 版、SurveyJS Dynamic Matrix。** 前者适合可重复子表单，后者适合测量表在窄屏转为纵向列表。
- **需要平板仍像纸质表格：Jspreadsheet CE。** 有触屏事件、单元格编辑与合并；移动键盘、滚动冲突和科学计数法仍需实测及适配。
- **研究完整移动采集流程：Epicollect5、Enketo/ODK、Field Book。** 分别提供跨平台表单、Web/Android 离线采集、按观测对象快速录值的思路，不能混同为现成教学批阅系统。
- **将来独立做 Flutter App：worksheet。** 有专门移动手势与单元格编辑实现，但接入现有 Vue 的成本高。

没有核实到同时覆盖 LabMate 全部规则的大学物理实验移动成品。当前更有复用价值的是采集表单、网格及输入组件。

## 一、Vant：最容易增强现有手机录入

- 仓库：[youzan/vant](https://github.com/youzan/vant)
- 定位：Vue 移动 Web UI 组件库，不是表格或教学平台。
- 授权：[MIT](https://github.com/youzan/vant/blob/main/LICENSE)。最近推送：2026-10-26。[元数据](https://api.github.com/repos/youzan/vant)
- 源码证据：[NumberKeyboard.tsx](https://github.com/youzan/vant/blob/main/packages/vant/src/number-keyboard/NumberKeyboard.tsx) 有触屏事件、输入/删除/失焦事件；[中文说明](https://github.com/youzan/vant/blob/main/packages/vant/src/number-keyboard/README.zh-CN.md) 展示 readonly Field 配合虚拟键盘、额外按键和键高配置。
- 对 LabMate 的用法：点击测量格后打开固定底部输入区，显示“第几次测量、变量、单位”，用大按键输入；补“上一格/下一格/下一次测量”，不要让每个单元格撑开一套键盘。
- 边界：标准组件不是科学输入键盘。`custom` 主题支持两个额外按键，但负号、小数点、指数 `e`、光标插入和撤销仍应统一设计，不能只当金额输入处理。
- 离线：该组件本身不提供持久化或跨设备同步；继续使用 LabMate 的 IndexedDB 与服务端草稿。
- 演示入口：[Vant 数字键盘](https://vant-ui.github.io/vant/#/zh-CN/number-keyboard)。

## 二、FormCreate 移动端：教师设计、学生重复填写

- 仓库：[xaboy/form-create](https://github.com/xaboy/form-create)、[xaboy/form-create-designer](https://github.com/xaboy/form-create-designer)。二者是同一生态的渲染器与设计器，不算两条独立方案。
- 移动版本：`@form-create/vant` 和 `@form-create/vant-designer`，Vue 3 + Vant。
- 授权：移动渲染器和移动设计器各有 [MIT LICENSE](https://github.com/xaboy/form-create/blob/next/packages/vant/LICENSE)、[MIT LICENSE](https://github.com/xaboy/form-create-designer/blob/next/packages/vant/LICENSE)。最近推送分别为 2026-10-08 和 2026-09-16。
- 已核实：[Vant group.jsx](https://github.com/xaboy/form-create/blob/next/packages/vant/src/components/group.jsx) 用数组模型承载重复子表单，有增删、数量上下限、禁止编辑和事件；[设计器子表单菜单](https://github.com/xaboy/form-create-designer/blob/next/packages/vant/src/config/menu.js) 真实存在。官方[说明](https://www.form-create.com/v3/guide/)将 Vant 列为移动端渲染器。
- 适合实验：“第 1 次测量：U/I/t”“第 2 次测量：U/I/t”，每次是一张卡片，点击增加一组。教师仍可在电脑设计模板，学生在手机填。
- 不等于：任意合并表头的 Excel 设计器。`group` 与复杂二维网格是不同模型；若按每行生成卡片，需要从 LabMate 的稳定 row/cell/field ID 转换，而不是直接用数组下标代替记录 ID。
- 离线和版本控制需 LabMate 自建；现有教师设计器已经有功能，不建议仅为引入库重做全部模板。
- 演示：[移动版设计器](https://form-create.com/v3/mobile/)、[重复子表单](https://www.form-create.com/v3/guide/group)。后者部分演示为桌面 UI，移动能力以 Vant 源码为准。

## 三、Jspreadsheet CE：保留平板可编辑表格

- 仓库：[jspreadsheet/ce](https://github.com/jspreadsheet/ce)
- 技术：JavaScript，可通过 Vue wrapper 或生命周期挂载接入。
- 授权：[MIT](https://github.com/jspreadsheet/ce/blob/master/LICENSE)；当前核查 `package.json` 为 CE 5.0.4，另有不同范围的商业 Pro。最近推送：2026-10-14。[元数据](https://api.github.com/repos/jspreadsheet/ce)
- 已核实：[events.js](https://github.com/jspreadsheet/ce/blob/master/src/utils/events.js) 注册 touchstart/touchend/touchcancel/touchmove；[editor.js](https://github.com/jspreadsheet/ce/blob/master/src/utils/editor.js) 提供单元格编辑；[merges.js](https://github.com/jspreadsheet/ce/blob/master/src/utils/merges.js) 提供合并；另有行列、历史、冻结等源码模块。[官方 CE 文档](https://bossanova.uk/jspreadsheet/docs)有 Vue 集成。
- 优先用途：平板横屏的“测量次数 × 多个物理量”数据表、表头合并、固定单位、限制编辑区域。
- 移动证据边界：README 有 mobile/touch 改进记录，源码确有触摸事件，但不等于已验证所有 iOS 键盘/触屏多选体验；本次未做真机测试。
- 需重点试：单击还是双击编辑；手指滑动是滚动还是选区；输入时表头是否可见；负数/指数能否录入；蓝牙键盘与触屏切换；横竖屏后焦点是否保留。
- 不负责：离线可靠保存、教师权限、任务版本与不可变提交。
- 演示：[CE 使用与示例](https://bossanova.uk/jspreadsheet/docs)、[合并单元格](https://bossanova.uk/jspreadsheet/docs/merged-cells)。按对应 CE 版本选示例，不能直接照搬 Pro 页面所有功能。

## 四、Epicollect5：Vue 的完整移动数据采集端

- 仓库：[epicollect5/epicollect5-mobile-app](https://github.com/epicollect5/epicollect5-mobile-app)
- 技术：Vue 3 + Ionic Vue + Capacitor；有 Android、iOS 及网页构建路径。
- 授权：[MIT](https://github.com/epicollect5/epicollect5-mobile-app/blob/master/LICENSE)。[README](https://github.com/epicollect5/epicollect5-mobile-app/blob/master/README.md)另明确 fork 发布需另取名称，未授权原名称/标志。最近推送：2026-10-20。[元数据](https://api.github.com/repos/epicollect5/epicollect5-mobile-app)
- 已核实录入模块：[EntriesAdd.vue](https://github.com/epicollect5/epicollect5-mobile-app/blob/master/src/pages/EntriesAdd.vue)、[QuestionDecimal.vue](https://github.com/epicollect5/epicollect5-mobile-app/blob/master/src/components/questions/QuestionDecimal.vue)、[QuestionGroup.vue](https://github.com/epicollect5/epicollect5-mobile-app/blob/master/src/components/questions/QuestionGroup.vue)、[QuestionBranch.vue](https://github.com/epicollect5/epicollect5-mobile-app/blob/master/src/components/questions/QuestionBranch.vue)。Decimal 组件有 `inputmode="decimal"`；group 同屏多个问题，branch 支持重复子记录。[官方 Branch 说明](https://docs.epicollect.net/formbuilder/branches)、[Group 说明](https://docs.epicollect.net/formbuilder/groups)
- 明确区分：`GridQuestionNarrow.vue` / `GridQuestionWide.vue` 是 Ionic 的问题布局包装器，不是可编辑二维实验表。它值得借鉴的是窄屏排版、数字问题、成组问题和重复记录流程。
- **关键离线边界**：[ARCHITECTURE.md](https://github.com/epicollect5/epicollect5-mobile-app/blob/master/docs/ARCHITECTURE.md) 明确 native 模式是 SQLite、offline-first；名为 PWA 的网页目标是历史叫法，当前没有 service worker、manifest 或离线支持。不能因为脚本叫 `pwa:*` 就认为浏览器断网能续填。
- 源码对应：[原生保存](https://github.com/epicollect5/epicollect5-mobile-app/blob/master/src/services/entry/save-entry-native.js)、[网页保存](https://github.com/epicollect5/epicollect5-mobile-app/blob/master/src/services/entry/save-entry-pwa.js)、[SQLite 服务](https://github.com/epicollect5/epicollect5-mobile-app/tree/master/src/services/database)。
- 适配成本：中到高。不能只改服务器 URL 就接入 FastAPI；需映射项目/问题/答案 Schema、鉴权和上传协议，原地图/登录等能力不是 LabMate 的前置依赖。
- 演示参考：[官方示例项目说明](https://docs.epicollect.net/extra/demo-projects)。公开 demo 不用于真实学生数据。

## 五、Field Book：最像现场重复测量的输入交互

- 仓库：[PhenoApps/Field-Book](https://github.com/PhenoApps/Field-Book)
- 定位：面向田间试验观测的 Android App；Java/Kotlin，不是 Vue 网页或 iPad App。
- 授权：[GPL-2.0](https://github.com/PhenoApps/Field-Book/blob/main/LICENSE.txt)。最近推送：2026-10-23。[元数据](https://api.github.com/repos/PhenoApps/Field-Book)
- 为什么相似：虽然研究领域不同，但“样本/对象 × 测量项 × 重复测量”与物理实验原始记录十分接近。[Numeric Trait 文档](https://github.com/PhenoApps/Field-Book/blob/main/docs/traits/trait-numeric.md)包含最小/最大值、小数位、单位、数学符号和 repeated measures。
- 实际代码：[NumericTraitLayout.java](https://github.com/PhenoApps/Field-Book/blob/main/app/src/main/java/com/fieldbook/tracker/traits/NumericTraitLayout.java)有范围/小数位校验及数字录入处理。
- 交互值得学：[Collect](https://github.com/PhenoApps/Field-Book/blob/main/docs/collect.md)只突出当前对象和当前测量项，用大导航按钮前后切换；[DataGrid](https://github.com/PhenoApps/Field-Book/blob/main/docs/datagrid.md)支持手指滚动、双指缩放、固定列，点单元格导航到相应输入位置，有重复测量时先选具体记录。
- 边界：该 DataGrid 不应宣传成原位编辑 Excel；“点格进入大输入区”的设计反而值得 LabMate 借鉴。它的可切换锁定不等于 LabMate 服务端不可变提交。
- 离线证据：[Storage](https://github.com/PhenoApps/Field-Book/blob/main/docs/storage.md)说明数据使用本地 SQLite，并有备份、导入导出。其 BrAPI 和育种数据模型不能直接替代 FastAPI 接口。
- 适配：优先借鉴流程；若另做 Android 端再考虑 fork，不适合直接复制 Java 组件进 Vue。
- 演示：[官方手册](https://fieldbook.phenoapps.org/#/)。

## 六、worksheet：Flutter 触屏表格模块

- 仓库：[sjhorn/worksheet](https://github.com/sjhorn/worksheet)
- 技术/授权：Flutter/Dart，[MIT](https://github.com/sjhorn/worksheet/blob/main/LICENSE)。最近推送：2026-03-14。[元数据](https://api.github.com/repos/sjhorn/worksheet)
- 已核实：[移动交互文档](https://github.com/sjhorn/worksheet/blob/main/doc/MOBILE_INTERACTION.md)明确标记哪些已实现、部分实现或仅参考；[worksheet_widget.dart](https://github.com/sjhorn/worksheet/blob/main/lib/src/widgets/worksheet_widget.dart)有 `mobileMode`、平台检测、双击编辑与屏幕键盘相关实现；[gesture_handler.dart](https://github.com/sjhorn/worksheet/blob/main/lib/src/interaction/gesture_handler.dart)处理移动手势。
- 有价值的能力：双向滚动、选择手柄、双指缩放、双击单元格编辑，区分触屏滚动和鼠标拖选；文档也说明 iOS Safari 同步获取输入焦点的处理。
- 不要过度宣称：专用数字键盘、公式栏等部分内容只是 Excel 移动版参考，移动填充柄也未实现。README 的帧率、超大行数等不是本次实测。
- 适配：适合将来独立开发原生/Flutter 学生端；当前 Vue 项目主要读交互文档，不优先引入第二套渲染框架。

## 七、SurveyJS：手机与平板切换布局的重复测量表

- 仓库：[surveyjs/survey-library](https://github.com/surveyjs/survey-library)。Form Library 支持 Vue，使用 MIT；可视化 Creator 是另一个产品，不能把其商业授权和免费渲染库混同。
- 已核实：[Dynamic Matrix 官方 API](https://surveyjs.io/form-library/documentation/api-reference/dynamic-matrix-table-question-model)支持动态增删行、多种单元格编辑器；`displayMode` 可选 `table`、`list`、`auto`，默认 auto 按可用宽度选择表格或纵向列表。[v1.11.14 官方发布说明](https://surveyjs.io/stay-updated/release-notes/v1.11.14)明确说明窄屏转换。
- 对 LabMate 的价值：把“试次 / U / I / t”作为动态测量行；平板显示表格，手机显示纵向测量记录。比单纯把桌面网格缩小更值得优先试用。
- 边界：不是任意合并表头的 Excel；持久化、草稿版本和冲突合并仍由 LabMate 负责；实验符号、单位、有效数字与原始字符串需要自定义映射。
- 授权证据：[LICENSE](https://github.com/surveyjs/survey-library/blob/master/LICENSE)。本次没有运行或做真机验收。

## 八、现有 LabMate 的适配判断

本地核查发现现有 `StudentAssignmentPage.vue` 已有：按模板录入、字符串数值校验、IndexedDB 暂存、服务端草稿、版本冲突合并、组共享、自绘数字键盘。并不是从零缺少录入功能。

当前实现中，数字键盘开关使用初始化时的 `max-width: 680px`，表格 `min-width: 560px`，键盘在当前单元格内展开。这些代码提示应重点评估平板、横竖屏和键盘遮挡，并不等于已在真机确认故障。

建议同一模板和同一草稿保存逻辑提供两种显示：

| 手机窄屏 | 平板宽屏 |
|---|---|
| 每次测量一张卡片，当前字段大输入区 | 保留二维测量表和实验表头 |
| 大数字键盘、上一格/下一格、下一次测量 | 点单元格后在固定输入区编辑 |
| 显示“第几次/共几次”、变量、单位 | 固定表头/首列，当前行列高亮 |
| 记录输入后再回看整表 | 支持触屏滚动及外接键盘导航 |

选择显示方式应结合可用空间、触控能力及用户切换，不只看设备名称或固定手机宽度。手机卡片不能凭空推断复杂表头语义，应通过稳定字段 ID 和显式测量组配置转换。

实验数值要保留原始字符串，例如 `1.230`、`-0.002`、`1.2e-5`；是否规范化或舍入应由实验规则决定，不能由通用金额输入框自动处理。单位、符号和学生输入继续分开存储。

建议优先顺序：

1. 先用 Vant 或独立输入组件优化数字输入与固定编辑区，保留已有草稿同步。
2. 手机行卡片参考 FormCreate/SurveyJS；复杂模板继续保留表格总览。
3. 用 Jspreadsheet CE 与当前网格做小范围比较，先验证一个真实实验，不整体替换教师设计器。
4. 用 Field Book 的“表格总览→单项大输入区”与 Epicollect5 的重复子记录流程完善体验。
5. 只有明确需要安装 App、长期断网或更多设备功能时，再评估 Enketo/ODK、Epicollect5 native 或 Flutter。

## 九、不优先采用的候选与误区

- [supunlakmal/spreadsheet](https://github.com/supunlakmal/spreadsheet)：MIT，JS 原型中确有[触摸选区函数](https://github.com/supunlakmal/spreadsheet/blob/main/modules/rowColManager.js)和[移动样式](https://github.com/supunlakmal/spreadsheet/blob/main/styles.css)。但主要把表格保存在 URL hash，P2P 也不是 LabMate 的权限和共享模型。可参考触屏原型，不适合作为学生数据持久化底座；README 的浏览器支持表未经本次实测。
- [tinycld/calc](https://github.com/tinycld/calc)：README 明确描述 iPad 点击/软键盘/拖选，明确 iPhone 暂不支持、Android 没有测试面。本次根目录和 package.json 未见项目许可证，且依赖其工作区生态，不作为可直接复制的优先候选；README 提到的部分手工测试路径本次未能读取。
- [fishel-feng/soy](https://github.com/fishel-feng/soy)：README 确为大豆田间试验数据录入/Excel 导出 App，但 2018 年项目、未核实项目授权和当前可运行性，排在成熟采集方案之后。
- PhyX：已经验证其 CSV/Excel 上传和报告链，但目前不是手机逐格填写的现成方案。
- 不把“只读展示表格”“上传 Excel”“有响应式 CSS”“库带 touch 事件”直接等同“现场可用的手机实验数据录入”。

## 十、后续最小真机验收

选一个含 5 次重复测量、数个物理量和负数/小数/科学计数法的真实模板；分别在 iPhone Safari、Android Chrome、iPad 横竖屏上验证：点选/滚动区分、软键盘遮挡、上一格/下一格、输入原始精度、断网续填、关闭重开、同步冲突和组共享权限。模拟器或桌面窄窗口只能作为补充。

源码许可与原站备案仍分别处理。本次只保存调研文档，没有安装候选、改动学生端代码或把实验数据发送到第三方服务。

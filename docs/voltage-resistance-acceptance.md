# 阶段 0：伏安法测电阻验收基线

首个真实实验固定为“伏安法测电阻”，用于阶段 1～8 的端到端回归。教师最终确认前，本文件中的范围视为开发验收样例，不代表课程正式参数。

## 模板

- 数据列：电流 `I/A`、电压 `U/V`。
- 行数：最少 5 行，最多 30 行。
- 合理范围：`0.001 ≤ I ≤ 1 A`，`0 ≤ U ≤ 12 V`。
- 权威计算：以 `I` 为横轴、`U` 为纵轴做最小二乘直线拟合；斜率为电阻 `R/Ω`，同时给出截距与 `R²`。
- 图表：散点图与线性拟合线。
- 警告：数据不足、缺失/非法值、超范围、重复行，以及 `R² < 0.95`。
- 后续产物：带身份和服务器时间的数据图片、拟合图与四工作表 Excel。

## 回归样例

| 类型 | I/A | U/V | 预期 |
|---|---|---|---|
| 正常 | 0.10, 0.20, 0.30, 0.40, 0.50 | 2.03, 4.07, 6.10, 8.14, 10.17 | 斜率约 20.35 Ω，`R²` 接近 1，无范围警告 |
| 缺失 | 第三行电压为空 | 同上其余值 | 阻止正式提交，指出具体单元格 |
| 边界 | I=0.001、U=12 | 其余为正常值 | 边界值允许保存 |
| 超范围 | I=0 或 U=12.1 | — | 标记范围错误并阻止提交 |
| 相似 | 在正常数据的小数尾数与异常点位置上高度一致 | — | 后续阶段只产生“相似性风险”，不得自动认定抄袭 |

## 完整流程

教师创建班级并导入名单 → 创建模板草稿 → 验证并发布不可变版本 → 向班级发布任务 → 学生录入、恢复、计算和提交 → 生成产物 → 教师退回 → 学生新版本重提 → 教师通过。

阶段 0～3 的当前验收终点是“任务发布”；学生录入从阶段 4 开始。

# 物理实验记录工具：键盘输入对照表

> 用途：设计电脑端的物理实验数据记录工具，也可作为应用内的输入帮助。以下是**建议该工具实现的输入规则**，不是所有软件通用的快捷键。命令尽量沿用 LaTeX 和 Word 公式中常见的写法；具体软件的支持范围和转换方式可能不同。

## 先记住这几条

| 想输入 | 在本工具的“物理量／公式”字段键入 | 显示结果 |
|---|---|---|
| 希腊字母 | `\alpha`、`\Delta` | α、Δ |
| 下标 | `v_0`、`x_{max}` | v₀、xₘₐₓ（按数学排版显示） |
| 上标 | `x^2`、`10^{-3}` | x²、10⁻³（按数学排版显示） |
| 上下标同时存在 | `x_i^2` | xᵢ²（按数学排版显示） |
| 常用符号 | `\pm`、`\times`、`\approx` | ±、×、≈ |
| 根式、分式 | `\sqrt{x}`、`\frac{a}{b}` | √x、a/b（按数学排版显示） |

**字段分工：**物理量名称、公式和单位使用本对照表；测量值单元格保持数字输入，支持 `-1.25`、`1.25e-3` 等数值写法。单位放在列定义中，不要求每个读数重复输入。

**转换时机建议：**输入 `\` 后显示候选；按空格或 Tab 接受候选，输入 `_`、`^`、`)` 等边界字符时也可接受完整命令。Esc 保留原文，Ctrl+Z 撤销转换。粘贴原始符号和 LaTeX 写法都应支持。不要在普通备注中擅自把英文单词替换成符号。

## 1. 希腊字母

| 名称 | 键入 | 输出 | 常见物理用途 |
|---|---|---|---|
| alpha | `\alpha` | α | 角度、系数 |
| beta | `\beta` | β | 角度、系数 |
| gamma | `\gamma` / `\Gamma` | γ / Γ | 比热容比、伽马射线 |
| delta | `\delta` / `\Delta` | δ / Δ | 微小变化量 / 差值 |
| epsilon | `\epsilon` / `\varepsilon` | ϵ / ε | 介电常数、误差 |
| zeta | `\zeta` | ζ | 阻尼比 |
| eta | `\eta` | η | 效率、黏度 |
| theta | `\theta` / `\Theta` | θ / Θ | 角度 |
| iota | `\iota` | ι | 较少使用 |
| kappa | `\kappa` | κ | 热导率、曲率 |
| lambda | `\lambda` / `\Lambda` | λ / Λ | 波长、特征值 |
| mu | `\mu` | μ | 摩擦因数、微观参数 |
| nu | `\nu` | ν | 频率 |
| xi | `\xi` / `\Xi` | ξ / Ξ | 位移、随机变量 |
| pi | `\pi` / `\Pi` | π / Π | 圆周率、乘积 |
| rho | `\rho` | ρ | 密度、电阻率 |
| sigma | `\sigma` / `\Sigma` | σ / Σ | 标准差、求和 |
| tau | `\tau` | τ | 时间常数、转矩 |
| phi | `\phi` / `\varphi` / `\Phi` | ϕ / φ / Φ | 相位、磁通量 |
| chi | `\chi` | χ | 磁化率 |
| psi | `\psi` / `\Psi` | ψ / Ψ | 波函数 |
| omega | `\omega` / `\Omega` | ω / Ω | 角频率 / 欧姆符号 |

说明：不同排版系统对 ε/ϵ、φ/ϕ 的默认命令可能不一致。本工具应在帮助页明确显示实际字形，保存时保持用户选定的变体。外形与拉丁大写字母相同的希腊大写字母，可直接键入普通拉丁字母。

## 2. 上标、下标与修饰符

| 需求 | 键入 | 显示示例 | 说明 |
|---|---|---|---|
| 单字符下标 | `v_0` | v₀ | `_` 后接一个字符 |
| 多字符下标 | `x_{max}` | xₘₐₓ | 多字符必须用 `{}` 包住 |
| 单字符上标 | `x^2` | x² | `^` 后接一个字符 |
| 多字符上标 | `10^{-3}` | 10⁻³ | 负指数用 `{}` 包住 |
| 上下标组合 | `a_i^2` | aᵢ² | 可连续输入 |
| 向量箭头 | `\vec{F}` | F⃗ | 用于向量量名 |
| 顶部横线 | `\bar{x}` | x̄ | 常用于平均值 |
| 顶部点 | `\dot{x}` | ẋ | 常用于对时间的一阶导数 |
| 顶部双点 | `\ddot{x}` | ẍ | 常用于对时间的二阶导数 |
| 帽号 | `\hat{n}` | n̂ | 常用于单位向量、估计量 |

上表中的部分示例使用 Unicode 近似展示；实际编辑器应将上下标和修饰符保存为**可编辑的数学结构**。这样 `x_{max}` 中的 `max` 不会受“是否存在对应 Unicode 下标字符”限制，光标也能进入上下标修改内容。

## 3. 运算、比较与关系

| 键入 | 输出 | 含义或用途 | 可选的易记输入* |
|---|---|---|---|
| `\pm` | ± | 正负、测量不确定度 | `+-` |
| `\mp` | ∓ | 负正 | — |
| `\times` | × | 乘号 | — |
| `\cdot` | · | 点乘或乘号 | — |
| `\div` | ÷ | 除号 | — |
| `\approx` | ≈ | 约等于 | `~=` |
| `\neq` | ≠ | 不等于 | `!=` |
| `\leq` | ≤ | 小于等于 | `<=` |
| `\geq` | ≥ | 大于等于 | `>=` |
| `\propto` | ∝ | 正比于 | — |
| `\sim` | ∼ | 相似、同数量级等 | — |
| `\infty` | ∞ | 无穷大 | — |
| `\rightarrow` | → | 方向、变化至 | `->` |
| `\leftarrow` | ← | 反向箭头 | `<-` |
| `\leftrightarrow` | ↔ | 双向箭头 | `<->` |

\* “易记输入”是**本工具可选的快捷别名**，并非通用标准。建议先弹出候选供用户确认；尤其 `+-`、`~=`、`->` 在备注中可能具有字面含义，不应全局自动替换。

## 4. 公式结构与微积分

| 键入 | 显示示例 | 用途 |
|---|---|---|
| `\frac{a}{b}` | a/b（排版为分式） | 分数、比值 |
| `\sqrt{x}` | √x | 平方根 |
| `\sqrt[3]{x}` | ∛x | n 次方根 |
| `\sum_{i=1}^{n} x_i` | 从 i=1 到 n 的求和式 | 求和 |
| `\int_a^b f(x)\,dx` | 从 a 到 b 的积分式 | 积分 |
| `\partial` | ∂ | 偏导符号 |
| `\nabla` | ∇ | 梯度、散度等 |
| `\sin` / `\cos` / `\tan` | sin / cos / tan | 三角函数名 |
| `\ln` / `\log` | ln / log | 对数函数名 |

建议把 `\frac`、`\sqrt`、`\sum` 等作为模板：输入命令后生成可用 Tab 依次跳转的占位框，比要求用户手动配平所有花括号更容易使用。公式字段还应允许直接粘贴完整 LaTeX。

## 5. 物理实验常见完整输入示例

| 要记录的内容 | 键入 | 说明 |
|---|---|---|
| 初速度 | `v_0` | 作为列名；单位另设为 m/s |
| 位移变化量 | `\Delta x` | Δx；单位另设为 m |
| 时间间隔 | `\Delta t` | Δt；单位另设为 s |
| 平均速度 | `\bar{v}` | 带横线的 v；单位另设为 m/s |
| 角速度 | `\omega` | ω；单位另设为 rad/s |
| 电阻 | `R` | 列名 R；单位选择 Ω |
| 加速度单位 | `m/s^2` | 在**单位字段**显示 m/s² |
| 测量值 | `1.25e-3` | 在**数值字段**保存为 0.00125，可显示为 1.25×10⁻³ |
| 带不确定度的结果 | `9.81 \pm 0.02` | 在**结果字段**显示 9.81 ± 0.02；单位另设为 m/s² |
| 牛顿第二定律 | `F=ma` | 简单公式直接键入 |
| 平均值公式 | `\bar{x}=\frac{1}{n}\sum_{i=1}^{n}x_i` | 用于计算列或实验报告 |

**数值与排版不要混为一谈。** `1.25e-3` 是方便计算的数值输入；`1.25×10⁻³` 是展示形式。物理量符号、测量值和单位分别存储，便于计算、修改单位和导出。

## 6. 电脑端键盘操作建议

| 按键 | 建议行为 |
|---|---|
| `Tab` / `Shift+Tab` | 接受当前符号候选；在表格中移到下一格／上一格 |
| `Enter` | 完成当前读数并进入下一行；在公式候选中接受选项 |
| `↑ ↓ ← →` | 在表格单元格或公式结构中移动光标 |
| `Esc` | 关闭候选或退出公式编辑，不丢弃已输入内容 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销／重做，包括符号转换 |
| `Ctrl+C` / `Ctrl+V` | 复制／粘贴表格数据、Unicode 符号或公式文本 |
| `Alt+=` | 可作为“插入公式”的可配置快捷键，符合 Word 用户习惯；须检查是否与浏览器或系统快捷键冲突 |

候选框应同时显示“命令、符号、中文名称”，例如 `\rho  →  ρ  密度常用符号`。最近使用和当前实验用过的符号排在前面；对不熟悉命令的用户，保留可搜索的符号面板。

# Univer 教师模板设计器复用评估

调研日期：2026-10-26。对象：[dream-num/univer](https://github.com/dream-num/univer)。本文保留接入前的功能与适配评估；后续已按用户要求完成组合接入，当前实现见 [Univer 集成说明](./Univer集成说明_2026-10-26.md)。以下“未实现”描述指本次评估时点。

## 结论

**有可复用价值，最适合承担教师端的表格编辑画布。建议先做一个受控的单表试点，再决定是否替换当前画布。** 首批收益是成熟的选区、键盘操作、剪贴板和行列调整体验。物理量字段配置、数学符号输入、实验步骤、共享范围、后端校验和不可变发布版本继续由 LabMate 管理。

Univer 仓库开源部分使用 Apache-2.0；官方另有 Pro 商业扩展层。不能把官网展示的所有能力都当作仓库免费功能。尤其是 Excel 文件转换、协同和打印，需要单独核实 Pro 条款及服务部署。[仓库许可证](https://github.com/dream-num/univer/blob/dev/LICENSE)、[官方开源与 Pro 功能边界](https://github.com/dream-num/univer#-open-source-and-pro)

## 现有实现与可复用功能

本地比对文件：`frontend/src/components/SpreadsheetTableEditor.vue`、`frontend/src/templates/designer.ts`、`backend/app/templates/excel_import.py`。以下“建议”属于对 LabMate 的工程判断，不是 Univer 官方承诺。

| 能力 | LabMate 当前实现 | Univer 可复用部分与建议 |
| --- | --- | --- |
| 选区与批量操作 | 鼠标拖选矩形，右侧配置用途、文字与字段 | 可考虑复用成熟选区和快捷键体系；字段批量绑定仍走 LabMate 面板。[选区 API](https://docs.univer.ai/guides/sheets/features/core/range-selection) |
| 复制粘贴 | 当前组件未实现表格剪贴板处理 | **优先价值**：从外部 Excel 粘贴、仅粘贴值/格式/列宽等。粘贴后仍需过滤不支持的内容、限制尺寸并核对字段，不等于完整 XLSX 导入。[剪贴板说明](https://docs.univer.ai/guides/sheets/features/core/clipboard) |
| 行列增删、列宽、行高 | 已有行列数量调整、列宽滑杆；当前调整以表格末端增减为主 | 复用更完整的指定位置插入/删除、宽高调整，需同步维护字段和单元格映射。[行列 API](https://docs.univer.ai/guides/sheets/features/core/row-col) |
| 合并与拆分 | 已支持标题/说明合并，禁止输入格合并 | Univer 有对应核心命令；必须保留 LabMate 的输入格合并禁令，不能放开任意合并。[核心命令表](https://docs.univer.ai/guides/sheets/features/core) |
| 冻结 | 已支持顶部行冻结 | Univer 支持行列冻结；第一轮只映射现有顶部行，左侧列冻结需要先扩展 LabMate schema 和学生预览。[冻结 API](https://docs.univer.ai/guides/sheets/features/core/freeze) |
| 撤销/重做 | 当前使用最多 30 份表格快照 | 可用 Univer 命令机制统一表格操作；需防止画布与外部字段面板形成互相冲突的两套历史。[通用命令 API](https://docs.univer.ai/guides/sheets/features/core/general-api) |
| 多工作表 | 已有 `tables[]`，教师逐张配置 | 可映射成工作表标签；每张表仍用稳定 `table.id`，首轮可以只加载正在编辑的一张表。[工作簿模型](https://docs.univer.ai/guides/sheets/model/workbook-data) |
| 数据校验、下拉列表 | 自定义字段类型、枚举、必填、精度、范围、共享属性 | Univer 有开源校验插件，可改善编辑反馈；不能代替后端最终校验，也不能把范围提示擅自改为提交阻断。[数据校验插件](https://docs.univer.ai/guides/sheets/features/data-validation) |
| 文字/填充色/边框/对齐 | 当前网格主要用统一 CSS，单元格结构不包含完整样式模型 | Univer 有成熟编辑能力，但任意样式需新增白名单和前后端持久化协议，否则保存后会丢失。页面板块配色可直接优化现有 CSS，无需接入 Univer。[核心功能与菜单](https://docs.univer.ai/guides/sheets/features/core)、[单元格数据模型](https://docs.univer.ai/guides/sheets/model/cell-data) |

## 不能直接当作免费现成功能的部分

- **XLSX 导入导出**：官方使用 `@univerjs-pro/exchange-client`、`@univerjs-pro/sheets-exchange-client`，需要文件转换后端。快照转换不要求开启协同，但依然需要转换后端；“JSON 快照保存”与“Excel 文件导出”是两回事。官方当前文档还指出 1.2.0 起内置导入导出菜单已移除，宿主自行提供交互。LabMate 现有 openpyxl 导入应继续保留，阶段 5 的证据 Excel 导出仍由后端负责。[官方导入导出](https://docs.univer.ai/guides/sheets/features/import-export)
- **实时协同与编辑历史**：属于 Pro 扩展；本地撤销/重做不等于服务端协同或审计历史。LabMate 已有共享数据的版本冲突与修订记录，不应直接换成通用文档协同。[官方功能边界](https://github.com/dream-num/univer#-open-source-and-pro)、[协同说明](https://docs.univer.ai/guides/sheets/features/collaboration)
- **打印及截图衍生功能**：官方打印插件为 `@univerjs-pro/sheets-print`，部分截图功能也有授权限制；其客户端显示水印不能替代 LabMate 服务端固化到像素/PDF 的提交水印与哈希证据链。[打印功能](https://docs.univer.ai/guides/sheets/features/print)
- **计算引擎**：虽然仓库有开源公式引擎，但当前业务明确延后自动计算；不得因更换表格画布就执行任意导入公式。实验字段应继续引用稳定 key，而非用 A1 坐标替代物理量标识。[官方功能边界](https://github.com/dream-num/univer#-open-source-and-pro)、[选区赋值的公式解释规则](https://docs.univer.ai/guides/sheets/features/core/range-selection)

## Vue 3 接入方式与代价

官方提供 Vue 3 示例：在 `onMounted` 创建 Univer，在 `onBeforeUnmount` 释放；实例不要放进 Vue 深层响应式代理。可以在现有 Vue 页面内通过 DOM 容器承载，不需要将整个 LabMate 重写为 React。[官方 Vue 集成](https://docs.univer.ai/guides/sheets/getting-started/integrations/vue)

但 Univer 自身视图层基于 React，接入会增加相关运行时、CSS、语言包和编辑器包。建议以路由/组件懒加载限制教师端首屏影响，并实际测量构建产物与运行性能；本次没有安装或测量，不能承诺具体包体数字。[仓库兼容性与安装说明](https://github.com/dream-num/univer#-compatibility)

初次实验可从 `@univerjs/presets` 与 `@univerjs/preset-sheets-core` 开始，后续按插件模式精简。SDK 包要保持兼容的统一版本，使用官方公开 Facade API；不要拷贝散落内部文件到项目，避免跟随内部接口变化维护分叉。[官方快速开始](https://github.com/dream-num/univer#-quick-start)、[API 稳定性政策](https://github.com/dream-num/univer/blob/dev/docs/API_STABILITY.md)

## 保留 LabMate 领域边界的适配方案

建议数据流为：

`LabMate TemplateSchema → 适配器 → Univer 工作簿/画布 → 适配器 → TemplateSchema → 现有后端校验 → 保存或发布`

1. 每张表用 `table.id` 对应工作表 ID；`fields[].key`、类型、单位、精度、个人/共享属性由 LabMate 持有。字段名称或符号修改不得生成新的机器标识。
2. 维护单元格的用途与字段绑定映射。行列插入、删除、粘贴、合并、撤销后都要更新映射；不能只凭当前 A1 地址猜测绑定。Univer 单元格支持自定义数据，但在复制粘贴和结构操作中是否满足本项目语义，仍需试验后验证。[单元格模型](https://docs.univer.ai/guides/sheets/model/cell-data)
3. 将合并区转换为现有 `rowSpan/colSpan`，列宽映射 `columnWidths`，顶部冻结映射 `frozenRows`。当前只接受 2–201 总行、1–30 列，超限拒绝并提示，不能静默裁剪。
4. 通过命令前事件拦截非法操作，通过操作后事件更新侧栏/脏状态。菜单隐藏只改善交互；保存和发布时仍必须由后端校验。官方提供 `BeforeCommandExecute` 与 `CommandExecuted`，前者可以取消命令。[通用事件 API](https://docs.univer.ai/guides/sheets/features/core/general-api)
5. 不把 Univer 快照直接替换已发布的 `TemplateVersion.schema_json`。保存草稿、发布新版本和已发布任务引用旧版本的规则继续保留。
6. 第一期对未支持的公式、图片、富文本和复杂样式明确提示；不调用外部 AI 或云端文件转换服务传送学生数据。现有物理符号编辑器需要验证与 Canvas 文本表示的兼容性，不能假设其自定义排版会自动复现。

## 最小试点与验收建议

先增加可切回现有画布的教师单表试点，只接入选区、标题文字、输入格绑定、合并/拆分、列宽、顶部冻结和撤销/重做；确认适配器往返保存无丢失后，再试外部 Excel 仅粘贴值、多表标签及数据校验。

使用已有“力学综合实验”模板和合成数据验收：

- 旧模板加载、编辑、保存、重载后字段 key、合并区、宽度、冻结和共享属性一致；
- 插入/删除/复制粘贴/撤销不串绑字段；输入格合并、越界、未知字段被拒绝；
- Excel 开头为 `=` 的文本不变成可执行公式，尺寸超限不被静默截断；
- 保存草稿后发布新版本，不影响已发布任务；
- 页面切换后实例与事件监听被释放；验证实际浏览器、缩放和中英文输入体验；
- 比较首屏、包体、编辑响应时间与现有画布，再决定是否默认启用。

目前的工作是复用评估；以上试点尚未实现。当前样式优化可以独立交付，不依赖 Univer 引入。

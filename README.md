# LabMate 物理实验数字助手

LabMate 正在从静态交互原型升级为 Vue、FastAPI 和 PostgreSQL 驱动的真实系统。当前已完成开发阶段 0～3 的纵向切片：真实账号与角色权限、班级与 Excel/CSV 名单导入、可视化实验模板设计、白名单计算校验、不可变模板版本以及班级实验任务发布。

## 管理员后台设计约束（2026-10-27）

**管理员后台使用 Ant Design Pro 设计体系及官方 ProComponents。** `/admin` 独立使用 ProLayout、PageContainer、ProTable、ProForm 与 Ant Design；后续管理员后台页面沿用同一设计，不继续扩展教师工作台式的旧管理员布局。

- 项目主体仍是 Vue 3；管理员入口按需挂载独立 React 模块，不迁移教师/学生端，也不引入整套 Umi 应用脚手架。
- 管理员已有班级创建（指定教师）、学生名单查看、Excel/CSV 预览/确认导入、班级删除确认及退出登录均复用原 API；教师目录只读，不虚构账号管理接口。
- Vue 路由守卫、HttpOnly 会话、服务端资源授权保持不变；菜单显示不能代替权限校验。
- React 根节点与弹窗位于独立 Shadow DOM，卸载时清理；管理员依赖仅在通过角色检查进入 `/admin` 后加载，不能覆盖学生手机/平板样式或教师模板编辑器。
- 当前固定版本：ProComponents 2.8.10、Ant Design 5.29.3，沿用 React/React DOM 19.3.1，并使用 React 19 兼容包。升级须核验 peerDependencies 和三类角色回归。

详见 `docs/管理员后台AntDesignPro接入说明_2026-10-27.md` 与技术规格第 2.4 节。后台验收使用模拟 API：

```powershell
cd frontend
pnpm build
pnpm e2e:admin
```

## 学生端设备与页面尺寸约束（2026-10-27）

**学生使用手机和平板填写，学生端必须按移动设备设计并验收。** 电脑只是兼容入口，不能用桌面固定画布或整页缩放代替适配。教师/管理员工作台保留桌面布局。

- 学生登录/首次设置、任务列表、实验录入和后续提交/附件/反馈均采用自适应布局；标题、提示和操作区换行，页面不整体横向溢出。
- 宽实验表格保留原行列、合并关系、物理符号/单位和字段绑定，仅表格区域横向滑动，不删字段、不缩小整页。
- 手机和平板触控数值键盘固定在屏幕底部，适配横竖屏与安全区；按键至少 44 CSS px、输入字体至少 16 CSS px；旋转/尺寸变化不刷新、不丢数据。电脑仍可键盘录入。
- 自动保存、IndexedDB 离线恢复、共享权限、冲突处理及只读规则保持不变；新增学生端功能必须继续满足这些约束。
- 最小验收矩阵：320×568、390×844、844×390、768×1024、1024×768、820×1180、1180×820；另做桌面兼容与真实手机/平板人工验收。

权威需求见 `docs/LabMate_产品与技术开发规格_v2_2026-09-23.md` 第 2.3 节；实施与验收清单见 `docs/学生端手机与平板适配规范_2026-10-27.md`。本次修改落在仓库文档，不覆盖 `E:\Labmate` 中原始存档。

## 当前目录

- `frontend/`：Vue 3、TypeScript、Vite、Pinia 和 Router 主应用；`src/admin/` 为独立按需加载的 React + Ant Design ProComponents 管理员后台。
- `backend/`：FastAPI、SQLAlchemy 和 Alembic 后端。
- `deploy/`、`compose.yaml`：本地 PostgreSQL 与全栈开发环境。
- `dist/`：迁移期保留的静态演示原型，不参与新系统的数据与权限判断。
- `docs/voltage-resistance-acceptance.md`：阶段 0 的伏安法测电阻验收样例。

## 本地启动

前置条件：Docker Desktop 已安装并正在运行。

1. 将 `.env.example` 复制为 `.env`，设置本地数据库密码。演示模式无需设置师生账号密码。真实鉴权模式请使用独立数据库，并设置教师和管理员的种子密码；学生首次使用姓名、学号、短信验证码自行设置密码并绑定手机号。
2. 启动完整环境：

   ```powershell
   docker compose up --build -d
   ```

3. 首次创建匿名开发账号：

   ```powershell
   docker compose exec api python -m app.seed
   ```

4. 打开 <http://localhost:5173>。本地 Compose 默认开启演示登录：密码填写任意非空内容，无需正式设置密码。
   - 学生：仅使用教师已导入班级名单中的学号；不存在或未导入的学号不能登录。
   - 教师：`t0001`
   - 管理员：`admin`

   演示模式不提供密码保护，只能用于本地演示，不显示学生首次设置入口。设置 `DEMO_AUTH_ENABLED=false` 后使用真实鉴权：测试学生以“测试学生 / 20260001”进入首次设置。本地联调时还需显式设置 `SMS_DELIVERY_MODE=test` 和六位 `SMS_VERIFICATION_TEST_CODE`；该测试模式不得用于生产环境。

停止环境：

```powershell
docker compose down
```

只需在本机预览已经构建好的前端时，也可以使用轻量启动器。它会在同一端口提供 Vue 页面、FastAPI 接口和 SQLite 演示数据，并支持直接刷新 `/teacher` 等前端路由：

```powershell
cd backend
.\.venv\Scripts\python.exe preview_server.py
```

随后打开 <http://127.0.0.1:8010/>。启动器会创建缺失的演示账号；遇到旧版预览数据库时会先备份再迁移，保留已有名单和班级。

## 当前功能范围

- 教师可创建自己负责的班级；管理员可为指定教师创建班级。
- 名单支持 `.xlsx` 和 `.csv`，只要求“学号、姓名”两列；目标班级在上传前选择，旧文件中的班级代码、班级名称和学期列会被忽略。系统先预览并逐行校验，再通过数据库事务确认导入；新学生不生成初始密码。
- 教师可从“力学综合实验”预设或空白模板开始，可视化配置实验目标、预习问题、操作步骤、多张数据表、测量名称/类型/符号/单位/范围、个人或同组共享属性，以及受控变量令牌公式，无需编写 JSON 或可执行代码。
- 教师也可导入 `.docx` 实验报告，系统提取可识别的名称、文字和数据表为待核对草稿；已有模板可点击查看/继续编辑，也可从列表删除。删除不会清除已发布任务及历史数据。
- “力学综合实验”预设由真实实验报告整理而来，包含不同振幅周期、不同质量周期、弱阻尼平衡位置速度和速度峰值变化四组数据记录。
- 新建数据表可先指定数据行数和测量列数，每列自动生成可直接填写名称、符号、单位和录入类型的测量项。表格设计器也支持行列调整、表头合并/拆分、列宽、冻结行和撤销/重做；物理符号可通过快捷面板或 `Delta`、`_1`、`^2` 等快捷输入。
- 后端负责步骤与数据表标识、字段、共享范围、精度、范围、网格布局、计算依赖、坐标轴和受控函数白名单校验。
- 模板发布生成只读快照；后续修改只影响草稿，再发布时形成新版本。
- 教师可选择已发布模板版本和自己负责的班级发布实验任务，并在工作台查看、删除任务。删除立即隐藏任务和学生录入入口，相关草稿与组内记录进入固定 30 天保留区，可在期限内恢复；服务启动及运行期间定期清理到期任务。

阶段 4 已提供学生动态表格、IndexedDB/服务器双重草稿保存和组内共享录入；正式提交仍属于后续阶段。

## 教师模板的增强表格

每张数据表上方可切换“原表格 / 增强表格”，两种编辑器共用现有模板草稿。原表格和物理量设置、物理符号输入、Excel/Word 后端导入、保存校验及不可变版本发布均保留。

- 增强表格使用按需加载的 Univer 1.2.0 开源插件，提供画布、鼠标选区和键盘导航；方向键移动，Shift + 方向键扩选，Ctrl/Cmd + Z 撤销，Ctrl/Cmd + Shift + Z 或 Ctrl/Cmd + Y 重做。
- 双击标题/说明或按 F2、Enter，使用原有物理符号输入器编辑；保存模板或切换编辑器时会先确认正在编辑的文字。
- “粘贴表格文字”可把 Excel 复制的区域写入标题/说明。增强画布也接收纯文本粘贴；跨输入格、合并内部或表格边界的粘贴会整批拒绝，不会部分覆盖。
- 数据输入格保留测量项绑定；合并、拆分、列宽、冻结和行列数量继续使用 LabMate 工具栏。两种编辑器的改动共用撤销历史。
- 本次只注册表格渲染、选区及文字所需的开源插件，不接入公式计算、Pro 文件转换、云端协同或外部 AI。原始 `TemplateSchema` 与后端 API 不变。

增强表格只在主动切换时下载；依赖较大，低性能设备可继续使用原表格。接入边界与验收见 `docs/Univer集成说明_2026-10-26.md`，Apache-2.0 许可证随前端静态资源位于 `public/licenses/`。

## 安全说明

- 浏览器只保存默认有效期 30 天的 `HttpOnly` 会话 Cookie，不再通过 `sessionStorage` 推断角色。
- 账号与密码自动填充由浏览器密码管理器负责，网站不会把明文密码写入前端存储。
- 密码使用 Argon2id 摘要，数据库不保存明文密码。
- 后端统一执行角色授权；前端路由守卫只改善体验，不能代替服务端权限。
- 学生账号不会因连续输错密码而锁定；教师和管理员仍保留账号级暴力破解防护。首次设置和短信接口实施独立限速。
- 当前只使用匿名开发账号，禁止写入真实师生密码或个人信息。
